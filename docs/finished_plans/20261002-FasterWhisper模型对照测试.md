# FasterWhisper 模型对照测试计划（已完成）

## 范围

- [x] 使用同一个第 3 个真实视频比较 `tiny`、`small`、`medium`、`large-v3-turbo`。
- [x] 除模型外保持日语、CUDA、VAD 关闭、音轨、断句和连续重复清理完全一致。
- [x] 禁用 ASR 缓存；模型下载耗时不计入转录速度。
- [x] 不调用 DeepSeek，不覆盖视频旁正式 SRT；结果隔离到项目输出目录。

## 评价

- [x] 比较实际转录用时、原始/清理后 cue、字符量、时间覆盖、重复删除量和异常长 cue。
- [x] 以 `medium` 为当前基线，比较文本相似度和分时段缺失。
- [x] 抽查关键差异，给出速度、完整性和幻觉风险的推荐，不把单视频结论绝对外推。

## 交付

- [x] 保存四份原始/清理后 SRT、运行元数据、机器可读对比和结论。
- [x] 更新项目可复用测试上下文，归档计划并写复盘。
- [x] 运行 SRT 解析、统计产物和固定上游 clean 校验并提交本任务文档；正式配置保持 `medium`。

结果：`large-v3-turbo` 约 189.82 秒最快，但前 13 分钟大幅漏识别且产生 `U+FFFD`，正式校验失败；`small` 194.99 秒但原始 202 条中删除 127 条连续重复；`tiny` 312.68 秒最慢且混语幻觉严重；`medium` 288.04 秒，对白连贯性和全片覆盖最佳，因此继续作为正式模型。
