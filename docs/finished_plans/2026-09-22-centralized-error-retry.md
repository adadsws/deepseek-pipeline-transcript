# 批处理错误集中重试

## 需求

- 所有视频先完整处理一轮，过程中不询问是否重试。
- 已有成功凭证且校验正确的 SRT 继续跳过。
- 一轮结束后集中显示失败视频和错误类别，再统一选择重试哪一类。
- 轮末提供 4 个数字选项：只重试 DeepSeek、只重试 `invalid_or_blank_srt`、两类都重试、不再重试。
- 重试后的最终报告按视频合并状态，并累计各次尝试的错误、Token、费用和用时。
- 修复后实际处理指定目录，集中重试首轮错误。

## 设计

- 保留 `process_video()` 的单次处理职责，移除其中的即时 DeepSeek 交互。
- 在 `_run_batch()` 外层按轮次组织待处理视频；首轮处理全部发现的视频，后续轮次只处理用户选中的失败类型。
- 每轮结束后通过统一菜单决定重试失败项或结束；成功和已验证跳过项不进入后续轮次。
- 用视频路径为键替换最终结果，同时合并历史错误和 Token 统计，避免报告中一个视频出现多行。
