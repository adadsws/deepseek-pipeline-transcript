# 改用序列相邻重复清理复盘

## 项目专项复盘

- 最终规则只依赖字幕序列顺序：规范化文本连续相同即保留第一条，不再依赖时间距离、出现次数或全片分布。
- 实现同时移除了不再生效的六个阈值、周期统计、碎片合并及对应报告字段，避免配置保留虚假可调项。
- 指定视频端到端从 103 条清理为 66 条，删除 37 条；1 次 DeepSeek 请求后全部 66 条双语 cue 通过严格校验并原子发布。
- 该规则会删除时间上相隔较远但序列连续相同的真实短句，也会保留被其他文本打断的重复组；这是路线 E 实测后用户明确接受的取舍。

## 跨项目通用实践

- 用户基于对照结果选择风险更高的确定性规则时，应准确固化其语义并删除旧规则残留，不能暗中保留“更安全”的额外过滤。
- 配置、运行统计、测试名称和用户文档必须随算法语义一起重命名，否则历史术语会让实际行为难以审计。
