# FasterWhisper 模型对照测试复盘

## 项目专项复盘

- 在 VAD 关闭、静音和弱语音较多的素材上，模型更大或名称带 `turbo` 不代表字幕更完整；本次 `large-v3-turbo` 虽最快，却漏掉前 13 分钟的大部分对白。
- `small` 的重复幻觉最集中，当前连续重复清理可将 202 条降为 75 条，但被其他文本打断的模板仍会保留，因此不能仅用清理后句数评价模型。
- `tiny` 的字符量最高却充满混语和破碎长句，说明字符量、覆盖时间和 cue 数都只能作为异常信号，必须结合实际文本抽查。
- `large-v3-turbo` 生成一个 `U+FFFD`，会被发布前严格校验正确拦截。为做对照，只在分析副本中移除该字符，原始证据保持不变。
- `medium` 在本样本上保持最好的对白连贯性与分时段覆盖，正式配置无需因速度测试而变更。

## 跨项目通用实践

- ASR 模型对照应预先下载、关闭缓存、固定解码参数，并把下载时间与推理时间分开。
- 没有人工真值时，不能把某个模型直接当作准确率真值；应同时看分时段缺失、重复模板、语言混杂、结构合法性并人工抽查。
- 性能最快但产物无法通过正式校验的候选不能直接上线；兼容性失败本身就是模型评测结果，而不是应静默修复的数据噪声。
- 复用历史基线必须确认输入、缓存、设备和参数完全一致，并明确标注；从文件时间戳恢复的耗时只能写成近似值。
