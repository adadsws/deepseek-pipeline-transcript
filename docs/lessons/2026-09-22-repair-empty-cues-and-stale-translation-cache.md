# 空白 cue 与坏翻译缓存复盘

## 项目专项复盘

- FasterWhisper 可能输出仅含连字符或纯标点的 cue；在翻译前按 Unicode 字母/数字判定正文、删除无语义块并重编号，可以保留其余有效字幕。
- DeepSeek 重试需同时绕过一小时 LLM 响应缓存和七天分块翻译缓存；成功响应应回写分块缓存，避免后续继续命中坏结果。
- 自动修复事件应保留在错误统计中，但与最终失败状态分开呈现。

## 跨项目通用实践

- 缓存刷新应限定到用户明确重试的失败工作单元，避免全局清缓存造成无关重算和额外费用。
- 可恢复的数据瑕疵应先做最小修复再严格校验，并同时保留修复审计记录。
- Windows 控制台可能在非交互管道中回落到 GBK；关键状态文本优先使用可跨代码页输出的单位字符。
