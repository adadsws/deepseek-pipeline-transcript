# 发布项目并更新 GitHub 主页复盘

## 项目专项复盘

- 源仓库包含加密 secret、归档资料和独立历史，公开仓库只保留允许发布的文件；发布时应继续以公开仓库为基线，按已验证文件清单同步，不能直接推送源仓库历史。
- 发布后同时核对远端 `main`、父提交和目标文件 blob，能够证明历史连续且线上内容与本地发布内容一致。

## 跨项目通用实践

- 发布前把远端 SHA 作为并发保护条件；只有远端仍等于已审计基线时才更新 ref，并禁止 force。
- Git Smart HTTP 不可用但托管平台 API 可用时，可用 Git Data API 创建 blob、tree、commit，再以非强制方式更新 ref；仍需执行同等的范围、凭据和远端结果校验。
