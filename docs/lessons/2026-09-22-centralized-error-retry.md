# 集中错误重试复盘

## 项目专项复盘

- 上游翻译线程可能吞掉分块请求异常并输出残缺 SRT，因此重试判定必须覆盖翻译后的双语完整性校验，不能只依赖线程异常。
- 单次视频处理只返回结构化结果，轮次、分类选择、重试和统计合并统一放在批次编排层，可同时覆盖空白转录与 DeepSeek 残缺输出。
- 重试后的报告以视频路径合并最终状态，同时保留历次错误和 API 用量，避免重复视频行或漏算费用。

## 跨项目通用实践

- 批处理交互应放在一轮任务的边界，工作单元内部只产生结果，避免中途阻塞整批任务。
- 将“最终状态”和“历史尝试”分开建模：最终状态用于判断是否完成，历史事件用于审计、计费和问题统计。
