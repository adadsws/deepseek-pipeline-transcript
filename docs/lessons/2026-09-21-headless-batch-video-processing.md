# 无界面批量视频处理复盘

## 项目专项复盘

- 上游 CLI 不支持 GUI 当前使用的 FasterWhisper 路线；直接复用 `TranscriptThread` 与 `SubtitleThread` 可保持识别质量，并取得真实进度信号。
- 上游 `BatchProcessThread` 会在单项错误后继续取队列；需要在外层顺序编排，才能让 DeepSeek 错误可靠暂停。
- 原始/最终句子数统一按“合法时间轴且正文非空”的 cue 统计，同时可作为空白产物发布门禁。
- GUI 与批处理设置文件分离后，DeepSeek Key 应单独放入 `secrets/`，由两种入口运行时只读共享。

## 跨项目通用实践

- 批处理发布结果前先写临时目录并验证，再原子式复制到最终位置，避免失败时留下看似成功的空文件。
- 错误统计应同时保留最终状态与每次错误事件；重试成功不应抹去已经发生的限流或连接错误。
- 真实密钥迁移应先建立 Git 加密属性和外部恢复密钥，再写入 `secrets/` 并验证暂存 blob 头。
- 长批次同时显示当前任务进度和总体进度，并在外部服务错误时提供重试、跳过、终止三种明确恢复路径。
